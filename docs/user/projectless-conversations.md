# Projectless conversations

Use a projectless conversation when you want to talk to an agent without giving the thread a
repository. Choose **New conversation** from the command palette. If no projects exist yet, the
start screen offers the same action next to **Add project**.

A projectless conversation is a persistent thread, so it remains in the web and desktop sidebar
and can be renamed, archived, or deleted like other threads. The provider starts in an empty,
thread-specific working directory. Repository features such as branches, worktrees, source-control
status, terminals, checkpoints, and file diffs are unavailable because the thread has no project.

Projectless conversations currently appear only in the web and desktop clients. They are omitted
from mobile shell, archive, and search synchronization, so adding one does not change existing
mobile project or thread navigation.
