# Collaborative browser

Coding agents can use T3 Code's integrated browser to inspect and test a website without taking over your workspace.

When an agent starts browser automation, the browser stays hidden and the conversation shows a compact status such as **Codex is using the browser**. Select that status to open the Browser panel and watch or interact with the same tab. The status also works with Enter or Space from the keyboard.

The browser can still open immediately when you ask the agent to show it. Opening the Browser panel yourself, following a preview link, and other user-initiated browser actions are unchanged.
