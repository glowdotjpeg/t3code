# Composer controls

Choose a provider and model from the model picker. Reasoning effort, thinking, fast mode, and other
model-specific options appear at the bottom of that same picker when the selected provider supports
them.

Plan mode stays out of the composer until you enable it with the `/plan` command. While Plan mode is
active, a **Plan** control appears in the composer; select it to return to normal build mode. You can
also use `/default` to leave Plan mode.

The weekly percentage near the send button is the selected provider's reported rolling allowance.
Select it for the reset time and model-specific limits, or open the Usage page for token and cost
history.
